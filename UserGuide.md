# DoveChat — руководство пользователя

## 1. Вход и регистрация

При входе откроется форма авторизации, сначала выберите "Зарегистрироваться" введите email, на него придёт OTP-код, введите его в открывшуюся форму, далее откроются 2 поля для ввода пароля. Пароль придумайте сами, введие в оба поля, после можно входить через форму авторизации с почтой и паролем.

Если забыли пароль — нажмите «Забыли пароль?», введите email, перейдите по ссылке из письма.

---

## 2. Управление компанией

В разделе **Настройки → Компания** можно изменить название, реквизиты, настройку первого действия в CRM при подключении клиента, а также пригласить сотрудников и назначить им линии.

!!! После входа надо создать компанию или выбрать из имещихся и активировать ее, иначе не будут отображаться линии и диалоги.

Роли:
- **Владелец** — полный доступ ко всем разделам
- **Сотрудник** — работа в чате в определенных линиях, доступ к другим разделам закрыт.

## 3. Линии и каналы

**Линия** — К одной линии можно подключить все доступные каналы, каждый по одному.

### Создание линии

Раздел **Линии → Создать линию**. Укажите название, выберите каналы, оплатите.

### Подключение каналов

После создания линии найдите ее в списке линий, нажмите "Настроить", внутри нажмите настроить на нужном канале. 
После настройки убедитесь, что канал и линия подключены (линия - кнопка включить внизу под каналами, канал - переподключить справа)

**Telegram Bot**
1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Вставьте токен в поле и нажмите «Подключить».

> Создавать диалог вручную для Telegram Bot **не нужно и невозможно** — диалог создаётся автоматически, когда клиент сам пишет боту первым.

**Telegram User**
Есть 2 способа привязать канал к Telegram
1. - Введите номер телефона аккаунта Telegram.
   - Нажмите "получить код из Telegram". В приложение Telegram должен прийти код из нескольких цифр. Введите его в появившееся поле, нажмите "Сохранить и подключить" 
2. Отсканируйте QR-код в приложении Telegram: **Настройки → Устройства → Привязать устройство**. 
После сканирования нажмите ок и вас перекинет на предыдущую страницу управления линией.


**VK**
Подключение требует нескольких шагов со стороны VK — следуйте инструкции на экране или здесь.

Получите эти параметры в настройках приложения VK:
— главная страница VK → сообщества → ваша группа → управление → дополнительно → работа с API.
Access Token — во вкладке «Ключи доступа»
При создании ключа надо проставить галки:
Разрешить приложению доступ к сообщениям сообщества
Разрешить приложению доступ к фотографиям сообщества
Разрешить приложению доступ к документам сообщества
Остальные параметры — во вкладке Callback API:
ID группы — в сером блоке «type»: «confirmation», «group_id»: 123456789.
Код подтверждения — сразу под ним «Строка, которую должен вернуть сервер: 987654321»
Секретный ключ — придумайте сами из латинских букв и цифр и сохраните у себя.
Внимание! В форме настроек на сайте VK ничего сохранять (и нажимать кнопки) не нужно,
все параметры вводятся только в нашем интерфейсе, в его форме в настройке канала VK.


**WhatsApp Green API**
1. Нажмите «Подключить инстанс» — система выдаст QR-код.
2. Откройте WhatsApp на телефоне → **Связанные устройства → Привязать устройство**.
3. Отсканируйте QR. После успешного сканирования вы вернётесь в редактирование линии.

**WABA (WhatsApp Business API через 360dialog)**
1. Введите API-ключ от 360dialog.
2. Нажмите «Подключить».

## 4. Чат

### Создание диалога

Раздел **Чат → Новый диалог**. Выберите линию, канал, введите номер телефона или ID клиента и отправьте первое сообщение.

> **Для Telegram Bot создавать диалог вручную нельзя** — он создаётся только когда клиент пишет боту первым.

### Работа с диалогом

Отправка сообщений работает аналогично любому другому чату, например, Telegram. Для отправки файла нажмите на скрепку рядом с полем ввода.

## 5. Интеграция с Битрикс24

### Подключение

1. В Битрикс24 найдите и установите приложение DoveChat из Маркета.
2. В открывшейся форме введите email и пароль от DoveChat.
3. Выберите компанию и линию — подключение произойдёт автоматически.

После подключения в разделе **Открытые линии** Битрикс24 появится коннектор DoveChat.

### Входящие сообщения

Когда клиент пишет в подключённый канал, в правой части экрана Битрикс24 появляется уведомление. Нажмите на него, затем на открывшийся чат — и отвечайте клиенту там.

### Роботы

После установки приложения в Битрикс24 становятся доступны три робота DoveChat — их можно использовать в CRM-роботах и бизнес-процессах:

- **Отправить текст** — отправляет текстовое сообщение клиенту через подключённый канал
- **Отправить файл** — отправляет файл
- **Проверить аккаунт** — проверяет наличие аккаунта клиента в Telegram или WhatsApp

Роботы настраиваются стандартными средствами Битрикс24.

## 6. Административная панель

Доступна только администраторам системы по отдельному адресу.

### Дашборд

Общая сводка по системе — сводная статистика и последние действия на одном экране.

### Пользователи

Поиск по email, фильтры по статусу и роли. Доступны: блокировка аккаунта, сброс пароля, просмотр статуса.

### Линии

Поиск по названию, фильтры по статусу и каналу. Доступны: изменение статуса, продление, принудительная блокировка.

### Инстансы Green API

Управление пулом инстансов WhatsApp Green API: создание, удаление, принудительная очистка, перевыдача.

### Audit Log

Журнал событий и действий пользователей с фильтрацией по действию и типу объекта.

### Тарифы

Управление тарифными планами — список, создание, изменение, удаление.

### Компании (тенанты)

Поиск по названию. Просмотр статуса, привязанных линий и сотрудников.
